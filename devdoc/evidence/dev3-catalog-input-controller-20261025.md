# DEV3 Catalog 독립 입력과 native 실행기 검증

2026-10-25 · 완료된 입력 준비·실행기 검증을 사용자 요청에 따라 중간 커밋한다. 실제 Catalog CREATE → Commit → 새 프로세스 복구·조회 통합은 진행 중이며, 첫 Row INSERT 전 종료 조건을 유지한다.

## 완료 범위

- native N01/N02/N03 독립 기대값: 56행·16개 시점·221개 raw 파일·5,794,810바이트. 생성 1회와 별도 검산 1회를 완료했다.
- MC03 local 발급 간격과 MC04 Reserved Drop 기대값: 26행·6개 시점·137개 raw 파일·3,382,130바이트. 생성 1회와 별도 검산 1회를 완료했다.
- native 실행기는 원 source 전체 목록·ELF·입력·검토·자원 검사를 묶어 각 프로세스를 실행한다. 외부 ACK 기록, SIGKILL 및 회수, 재복구, WAL/페이지/Base3의 독립 비교와 실패 보존을 구현했다. 새 거부 시험 14개를 r0–r3의 해당 변경별로 통과했다. 완료 사례는 반복하지 않았다.
- 별도 검토자는 실행기의 현재 source를 수용했다. 입력 생성·검산과 실행기 자체 검증은 제품 내구성 성공 증거와 구별한다. 파일 지문과 원 결과는 [source별 기록](dev3-catalog-input-controller-20261025.json)에 보존한다.

## 진행 중인 제품 검증

N01의 r18 준비 용량 검사 실패, r21 시험 판독기 형식 오류, r25 정상 슬롯 부재를 fatal로 처리한 실패를 보존했다. 수정된 r27은 컴파일과 소스 자원 검사만 통과했고 실제 통합 재실행은 아직 하지 않았다. N02/N03과 memory 사례도 미실행이다. 이 커밋에는 진행 중인 Rust 제품·시험 변경을 포함하지 않는다.

별도 메모리 실행기는 보완·검토 중이므로 이 완료 커밋에서 제외한다. DEV3 전체 및 S5 완료를 선언하지 않는다.

## 자료 정리

복사된 ELF와 원 빌드 기록을 확인한 뒤 사용 완료된 r13–r20 컴파일 target을 정리해 730,807,525바이트를 회수했다. 원 FAIL, 로그, source 지문과 실행물은 보존했다.
