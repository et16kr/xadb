# 기능 상세화 안내

원문 파일명이나 특정 제품의 내부 symbol을 XADB의 기능 요구로 자동 승계하지 않는다. [기능 작성 목록](../plans/feature-design-inventory.md)의 topic별로 실제 공개 원문 URL·버전/commit을 확인하고 기능 의미·변형·오류·한도·환경 조합을 상세화한다. [제품 요구](../plans/product-requirements.md)는 유지한 capability·인수 제안이며 완전한 SQL overload 목록이 아니다.

[공개 참고 자료](opensource-references.md)의 비교 입력을 사용하고, 원문 조사 완료·명세 완료·제품 시험 완료를 구분한다.
